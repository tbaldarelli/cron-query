# Learning Task Gate

When executing a task from a spec that contains the phrase **"LEARNING TASK"** or **"MANUAL IMPLEMENTATION REQUIRED"**, you MUST:

1. Read the task and gather all relevant context (existing code, design docs, dependencies) as if you were going to implement it.
2. **STOP before writing any code or creating any files.**
3. Ask the user how they want to proceed — implement it themselves, or have Kiro do it.

This applies even if the user's prompt says "execute this task." The "execute" instruction means "initialize the context for this task," not "write the code immediately."

Do NOT rationalize past this rule. Do NOT treat it as optional or informational. It is a hard gate.
