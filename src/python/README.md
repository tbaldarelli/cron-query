# Python Implementation - Cron Query Tool

This directory contains the Python implementation of the cron-query tool. This was the first implementation, serving as the reference for other language implementations (Rust, Go).

## Structure

- `cron_query/` - Main package directory
  - Core functionality modules
  - CLI interface
- `tests/` - Test suite
  - Unit tests
  - Integration tests
  - Test fixtures

## Development

This implementation uses:
- Python 3.7+
- croniter for cron expression parsing
- pytest for testing
- setuptools for packaging

See the root directory's README.md for full project documentation.
